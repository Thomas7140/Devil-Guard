Devilish Services Nova Lobby - Universal DFX Template
======================================================

All three main game lobbies now use EXACTLY the same PHP page renderer.

MASTER TEMPLATE
===============

Shared PHP markup:

    /includes/lobby-ui.php

Shared layout and themes:

    /assets/lobby.css

The Delta Force Xtreme lobby is the reference design.

These three pages all call the same function:

    lobby_render_index(...)

Files:

    /bhd/index.php
    /DFX/index.php
    /dfx2/index.php

Because the HTML is generated by the same PHP function, BHD, DFX and
DFX2 cannot have different lobby structures anymore unless the shared
template itself is changed.

COLOR THEMES
============

The structure is universal, but each game has its own color theme.

BHD:
    body[data-lobby-theme="bhd"]
    military green

DFX:
    body[data-lobby-theme="dfx"]
    blue / steel / cyan

DFX2:
    body[data-lobby-theme="dfx2"]
    orange / brown

All theme variables are stored near the top of:

    /assets/lobby.css

To change only a game's colors, edit that game's theme variables.

To change layout/spacing/table/filter behavior for every lobby, edit:

    /includes/lobby-ui.php
    /assets/lobby.css

BHD
===

The BHD page now directly uses the universal renderer.

It keeps the existing BHD data system by loading:

    /bhd/bootstrap.php

and then using the existing functions when enabled:

    parse_novahq()
    parse_novaworld()

The raw BHD server data is normalized into the same server-row format
used by DFX and DFX2.

BHD retains source-specific View links such as:

    server.php?source=novahq&id=<server id>

The BHD server list uses:

    /images/DFBHD.avif

Theme:
    bhd

IMPORTANT:
Upload the package OVER the existing nova-lobby site. Do not delete the
existing /bhd/ directory first, because the BHD bootstrap/parser/server
files already on the server are still required.

DFX
===

DFX uses the universal renderer with its existing database:

    /home/devilishservices/connections/dfx/db.php

Tables:

    dfx_servers
    dfx_server_players

Lobby image:

    /DFX/dfx.webp

Theme:
    dfx

DFX2

Theme:

CENTRAL FILES
=============

There are now only two files that define the universal lobby appearance:

    /includes/lobby-ui.php
    /assets/lobby.css

Do not create separate lobby.css copies inside BHD, DFX or DFX2.
